# 反馈与致谢

---

## 问题反馈

欢迎反馈问题、交流用法或参与贡献。下面按**目的**列出入口，方便你选择最合适的渠道。

### 我该去哪里问？

| 你的情况                     | 建议渠道                                                                               |
| ---------------------------- | -------------------------------------------------------------------------------------- |
| 疑似 Bug、崩溃、无法部署     | [GitHub Issues](https://github.com/LiuShen-Fork/Ech0/issues)（尽量带版本、环境、复现步骤） |
| 功能想法、用法讨论、经验分享 | [GitHub Discussions](https://github.com/LiuShen-Fork/Ech0/discussions)                     |

提 Issue 前可先搜是否已有相同问题；附上 **部署方式**（Docker / 二进制等）、**版本**与**日志片段**会更容易被定位。

### 链接

- **Bug 与缺陷**：[GitHub Issues](https://github.com/LiuShen-Fork/Ech0/issues)
- **讨论与问答**：[GitHub Discussions](https://github.com/LiuShen-Fork/Ech0/discussions)

### 参与贡献

代码与文档仓库：[LiuShen-Fork/Ech0](https://github.com/LiuShen-Fork/Ech0)。若你修复了 Bug 或改进了文档，可以提交 Pull Request；较大改动建议先在 Discussion 中沟通方向。开发环境见 [开发指南](/docs/dev/guide)。
